# 総論(総説 A〜N)執筆システム — Google Apps Script

総論の書き方は Minds の系統的レビューとは異なる(記名の解説。推奨の強さを書かない)。そのため、SR の流れ(ポータル)とは分けて、Google ドキュメントを原稿とする仕組みにする。
ウェブアプリの公開は行わない(組織の制限)。管理用スプレッドシートに結合したスクリプトと、そのサイドパネルだけで動く。

## 機能
| 機能 | 内容 |
|---|---|
| 前回版の閲覧 | 2023年版の総論の本文を、段落 ID(`GL2023-総論H-p010`)付きでパネルに表示。原文の Google ドキュメントも開ける |
| 文章作成 | 総論ごとに「2028年版 原稿」(Google ドキュメント)を作る。見出し: 1. 2023年版からの変更点、2. 本文、3. 図表、4. 文献(PMID)。版は Docs の版履歴。要約の下書き(原稿から)をパネルに出す |
| サマリー図表の自動提案 | 2023年版の本文と現在の原稿だけを根拠に、表(列の定義)・図(種類・軸・要素)の案を 3〜6 件作り、原稿の「3. 図表」と「図表案」タブに書く。表の骨組みの挿入、データからのグラフ画像(棒・折れ線)の挿入 |
| 共有保存 | ドライブ `JASCC_GL_総論/2028年版原稿/総論X/` に保存。担当表のメールアドレスの執筆者に編集権限。査読は Docs のコメント。状態(原稿未提出・執筆中・査読中・修正中・完了)は担当表。完了は統括委員会のみ |
| 作成経過 | 全操作を「作成経過」タブに追記 |

判断と文章の責任は執筆者。AI(Claude、Amazon Bedrock)は提案と下書きに限る。企画書にない項目・介入を提案に含めない(「規則」タブ)。

## 設置(統括委員長。15 分)
1. Google ドライブで新しいスプレッドシートを作る(名前: `総論管理`)。
2. 拡張機能 → Apps Script。既定の `コード.gs` の内容を `Code.gs` に置き換える。「＋」→ HTML で `Sidebar` を作り、`Sidebar.html` の内容を貼る。
3. プロジェクトの設定(歯車)→「appsscript.json をエディタで表示」を ON → `appsscript.json` の内容に置き換える(Drive API を使う)。
4. プロジェクトの設定 → スクリプト プロパティ: `BEDROCK_API_KEY` = 千葉大 AWS の Bedrock API キー(ポータルの `.env` の `AWS_BEARER_TOKEN_BEDROCK` と同じ)、`MODEL_ID` = `anthropic.claude-sonnet-4-5`(省略可)。
5. スプレッドシートに戻って再読み込み → メニュー「総論」→「初期設定」。初回は権限の承認。フォルダ `JASCC_GL_総論` と 19 件の原稿ができる。
6. `platform/soron/out/総論*.docx`(17 件)を、ドライブの `JASCC_GL_総論/2023年版原文(docx)` に置く → メニュー「総論」→「2023年版 docx を取り込む」。
7. 「担当表」タブの「メールアドレス」列に、執筆者のメールアドレスを入れる(名簿は Google フォームの回答から)。原稿の共有は、次回の「初期設定」実行で付く(既存の原稿は作り直されない)。または原稿を手で共有する。
8. 執筆者に、スプレッドシートを「閲覧者(コメント可)」で共有する。執筆者はスプレッドシートを開き、メニュー「総論」→「作業パネルを開く」で作業する。

## 執筆者の操作
1. 「作業パネル」で担当の総論を選ぶ。左に 2023年版の本文(段落 ID 付き)。
2. 「2028年版 原稿を開く」で Google ドキュメントを開き、本文を書く(2023年版の原文を土台に更新。引用文献に PMID)。
3. 「図表案を提案する」→ 案が原稿の「3. 図表」と図表案タブに入る。採否は執筆者。表は「表の骨組みを原稿に挿入」、図はデータを貼って「原稿に挿入」(グラフ画像)。
4. 「要約の下書き」→ 確認して原稿に貼る。
5. 状態を「査読中」にする。統括委員会が Docs のコメントで査読し、状態を「修正中」→ 修正後「完了」(統括委員会)。

## 制約
- 組織の Apps Script の設定で、学外の Google アカウントがスクリプトを実行できない場合は、執筆者はパネルを使えない。その場合でも、原稿(Google ドキュメント)の共有と執筆は行える。図表案の提案と要約は、事務局がパネルで代行し、原稿に入れる。
- 2023年版の本文は、`platform/soron/out` の docx(刊行版 PDF から切り出したもの)に基づく。K(漢方・鍼灸治療)と N(小児)は 2023年版に対応する節がない。
